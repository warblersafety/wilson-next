## Delivered boundary

For mapped known base values whose qualifiers are not carried, projection now
records a partial omission with exact current qualifier, stable fact target and
current resolved source IDs. B5 treatment/outcome/discharge-date omissions are
individual when unknown, declined, absent, inapplicable or conflicted; no extra
narrative is invented. Qualifiers on included stop statements/applicable medication
outcomes are disclosed too. Whole unsupported facts keep their existing separate
not-included disclosure. Product/test labels identify the relevant entity.

The existing coverage panel quotes omitted context, distinguishing a base value
included from an entire fact omitted. It opens for partial qualifiers. Output and
return-to-PDF messages no longer claim all accepted context reached the form.
The report content key still hashes actual output sections: metadata-only context
changes do not unnecessarily regenerate identical PDF values. This is explicit
partial-output disclosure, not incorporation of that context into the PDF itself.

The optional existing qualifier editor can be revealed for an unqualified known
fact. Reveal alone accepts nothing. Add/replace/remove/reopen/add use the same
server command, existing typed UI owner and source/superseded history. Unsubmitted
context survives durable reload without becoming accepted. No storage schema,
provider wire, model prompt, clinical authority or layout system changed.
