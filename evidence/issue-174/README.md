# Issue 174 — explicit patient race and/or ethnicity

Only fictional TEST-57 data are used. FDA Form 3500 (09/2025), A5 is a combined "Race and/or Ethnicity (Select all that apply)" field with seven categories. The current [FDA form](https://www.fda.gov/media/76299/download?attachment=) and [instructions](https://www.fda.gov/safety/medwatch-forms-fda-safety-reporting/instructions-completing-form-fda-3500) were checked: patient-reported selections, multiple allowed, do not guess.

The all-category and partial-response PDFs were generated by the application adapter. Independent pypdf traversal recorded native widget values, appearance states, rectangles and appearance streams in a5-appearance.json. macOS PDFKit rendered page 1 at 2x; both PNGs were visually inspected. All seven expected marks appear in the all-category export; only Hispanic or Latino appears in the partial-response export. Unselected categories are not negative responses. The partial response's unknown race context remains in the case, source and omission disclosure rather than being fabricated as an additional checkbox.

Unknown, declined, explicitly none of the listed categories, not applicable, and not supplied retain separate case states, while all produce blank A5 checkboxes. Known empty lists are rejected; unfinished checkbox drafts survive reload without changing accepted facts. Existing v7–v14 states migrate with only an empty new A5 fact, after strict historical-schema validation. No default or proxy-based inference is introduced.

Validation before review: 554 unit tests (63 files), typecheck, production build, all 93 mock Chromium journeys (including three new A5 journeys) passed. Final wording changes also passed 40 focused request/server/PDF tests. An earlier newly added source assertion exposed generic direct-edit source wording; the A5-only source now records human-readable selections and exact qualifier, and the full 554-test run passed after that fix. The three focused browser journeys additionally passed.

Application-model calls were mocked/blocked. Prompt tests inspect instructions and schema; these do not establish live-model compliance. Existing narrative, representation/capacity, diagnostic, list-scope and general semantic-correction gaps remain outside this slice.
